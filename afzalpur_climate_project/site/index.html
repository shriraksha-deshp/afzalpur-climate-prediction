Governing Formulations & Multi-Scale Calculations

1. Climatic Water Balance & Rectangular Rolling Sums:

For each month $t$ across timescale $k \in \{1, 3, 6, 12\}$:

$$D_t = P_t - \text{ET}_{0,t}, \qquad X_t^{(k)} = \sum_{j=0}^{k-1} D_{t-j}, \qquad R_t^{(k)} = \sum_{j=0}^{k-1} P_{t-j}$$
2. Direct SPEI Calculation via Generalized Logistic (GLO) Distribution:

Using calibrated monthly parameters $(\xi_{m,k}, \alpha_{m,k}, \kappa_{m,k})$:

$$Y_t = 1 - \frac{\kappa_{m,k}}{\alpha_{m,k}} \left( X_t^{(k)} - \xi_{m,k} \right), \qquad F\left(X_t^{(k)}\right) = \frac{1}{1 + Y_t^{1/\kappa_{m,k}}}$$ $$\text{SPEI}_t^{(k)} = \Phi^{-1}\left(F\left(X_t^{(k)}\right)\right) \approx \pm \left( W - \frac{c_0 + c_1 W + c_2 W^2}{1 + d_1 W + d_2 W^2 + d_3 W^3} \right), \quad W = \sqrt{-2\ln(P)}$$
3. Direct SPI Calculation via 2-Parameter Gamma Distribution: $$g(R) = \frac{1}{\beta^\alpha \Gamma(\alpha)} R^{\alpha - 1} e^{-R/\beta}, \qquad H\left(R_t^{(k)}\right) = q + (1 - q) G\left(R_t^{(k)}\right), \qquad \text{SPI}_t^{(k)} = \Phi^{-1}\left(H\left(R_t^{(k)}\right)\right)$$
4. Multi-Step Autoregressive Random Forest Regressor: $$\hat{y}_{t}(\mathbf{x}) = \frac{1}{B} \sum_{b=1}^{B} T_b\left(\sin\left(\frac{2\pi m}{12}\right), \cos\left(\frac{2\pi m}{12}\right), y_{t-1}, y_{t-12}\right)$$
